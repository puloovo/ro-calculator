上傳 GitHub Pages 避坑步驟

⚠️ 解決 404 錯誤的最重要關鍵：
  • 檔案名稱必須完全小寫為 index.html（不可叫 ro.html 或 Index.html）。
  • Repository 專案名稱不要加上 .html（建議命名為 ro-calculator）。
  1. 建立 Repository：
    在 GitHub 點擊 New，將專案命名為 ro-calculator。
  2. 上傳檔案：
    將下載好的檔案重新命名為 index.html，直接拖曳上傳至 Repository 根目錄。
  3. 開啟 Pages 服務：
    進入儲存庫的 Settings -> 左側 Pages。
  4. 設定 Branch：
    在 Source 選擇 Deploy from a branch，Branch 設為 main，資料夾選 / (root) 並按 Save。
  5. 等待發布：
    等待 1~3 分鐘後即可經由 https://yourname.github.io/ro-calculator/ 開啟網頁！
