免費上傳 GitHub Pages 步驟教學

步驟 1：下載/複製此 HTML 檔案

將這整段程式碼儲存為電腦中的 index.html 檔案。

步驟 2：建立 GitHub 儲存庫 (Repository)
  1. 登入 GitHub 並點擊右上角的 + -> New repository。
  2. 輸入名稱（如：ro-calculator）。
  3. 選擇 Public（公開），然後點擊 Create repository。
步驟 3：上傳檔案

在建立好的儲存庫頁面中，點擊 uploading an existing file，將剛剛的 index.html 拖曳上傳，並點擊 Commit changes。

步驟 4：啟用 GitHub Pages 免費網站
  1. 進入該儲存庫的 Settings 頁籤。
  2. 左側選單點擊 Pages。
  3. 在 Branch 下拉選單選擇 main (或 master)，資料夾選 /(root)。
  4. 點擊 Save。
約等待 1~2 分鐘後，您即可透過 https://yourname.github.io/ro-calculator/ 開啟您的專屬計算器網站！
